# Ola Cafe — сайт ресторана (меню, заказ, бронь стола)

Многостраничный сайт на **HTML, CSS и JavaScript** (без фреймворков). Дизайн, разметка и стили — из Ola Cafe (sage & cream, Cormorant Garamond + Jost).
Вместо Supabase все данные хранятся **в браузере (localStorage)**, поэтому сайт работает без сервера и без интернета (интернет нужен только для шрифтов Google).

## Запуск
Откройте `index.html` двойным кликом или через Live Server в VS Code.

Демо-доступ:
- Админ: `admin@olacafe.kz` / `admin123`
- Гость: `aigerim@mail.com` / `demo123`
- Или зарегистрируйте свой аккаунт на странице «Регистрация».

## Что есть
- **Регистрация, вход, выход**, личный кабинет (редактирование профиля, история заказов и броней, отмена брони)
- **Меню**: 16 блюд, поиск, категории, фильтр по цене; страница блюда (описание, особенности, цена); похожие блюда
- **Корзина → заказ → подтверждение → оплата** (стол, официант, комментарий к блюду)
- **Бронь стола**: дата, время (прошедшие слоты недоступны), гости, пожелания → подтверждение
- **Админ-панель** (только для роли admin): обзор, заказы (смена статуса), меню (создать / изменить / скрыть / удалить, фото), брони (подтвердить / отменить), пользователи (роль, удаление), возвраты, выручка по официантам
- **Telegram-уведомления** о заказах и бронях (по желанию, см. ниже)
- Адаптивность: ПК, планшет, телефон (на телефоне — нижняя навигация, как в Ola Cafe)

## Где хранятся данные
Ключи в `localStorage`: `ola_users`, `ola_menu`, `ola_orders`, `ola_reservations`, `ola_returns`, `ola_cart`, `ola_session`.
Открыть: F12 → Application → Local Storage. Сбросить к демо-данным: очистить Local Storage и обновить страницу.
Стартовые данные (блюда, пользователи) заданы в `js/db.js`.

## Telegram (необязательно)
В `js/config.js` заполните `telegram: { token: 'ТОКЕН_БОТА', chatId: 'ID_ЧАТА' }` — каждый новый заказ и бронь придут в чат.
Пока поля пустые, ничего не отправляется. Токен виден в коде сайта, поэтому для настоящего проекта отправку нужно делать через сервер.

## Структура
```
index.html  login.html  register.html  profile.html  admin.html
pages/   menu, dish, cart, order, payment, reserve, confirmation, about, privacy, terms
css/     styles.css (оригинал Ola Cafe) · pages.css (дополнения: меню сверху, футер, формы, профиль)
js/      config.js · db.js (данные) · validation.js · auth.js · layout.js (меню+футер) · client.js (гость) · admin.js
images/  logo.svg  (hero.jpg — по желанию, фон главной)
docs/    REQUIREMENTS.md — чек-лист по заданию
```

## Валидация (больше 5 случаев)
Пустое поле · пустая форма · неверный email · слишком короткий пароль · пароли не совпадают · email уже занят · пользователь не найден · неверный пароль · неверный телефон · дата в прошлом · время уже прошло · неверное число гостей / номер стола · не выбран официант или время · слишком длинный комментарий · цена блюда / сумма возврата.

## Примечания
- Пароли хранятся простым учебным хешем, роль админа проверяется в браузере. Для реального проекта нужен сервер.
- Данные видны только в том браузере, где их создали.
