# Чек-лист требований

| № | Требование | Где реализовано |
|---|---|---|
| 1 | Регистрация: имя, фамилия, email, пароль, подтверждение; необязательно телефон, дата рождения; проверка полей и уникальности email | `register.html`, `js/auth.js` |
| 2 | Вход: email, пароль, ссылка на регистрацию; ошибки (пустые поля, неверный email/пароль, нет пользователя) | `login.html`, `js/auth.js` |
| 3 | Главная: логотип, название, меню, информация, кнопки действия, данные пользователя, выход | `index.html`, `js/layout.js` |
| 4 | Навигация: все страницы доступны, текущая подсвечена, одинаковая везде | `js/layout.js` |
| 5 | Основной функционал (ресторан: меню и заказ + бронь стола) | `pages/menu`, `cart`, `order`, `reserve` |
| 6 | Карточки, 6–8+ позиций | 16 блюд, `dishCard()` в `js/client.js` |
| 7 | Страница деталей: фото, описание, особенности, цена, кнопка | `pages/dish.html` |
| 8 | Форма заказа / брони | `pages/order.html`, `pages/reserve.html` |
| 9 | Подтверждение с номером, датой, временем | `pages/confirmation.html` |
| 10 | Профиль: имя, email, данные, редактирование, история, выход | `profile.html` |
| 11 | Админ-панель: пользователи, блюда (добавить/изменить/удалить), заказы и брони, смена статуса | `admin.html`, `js/admin.js` |
| 12 | CRUD | Админка → Меню |
| 13 | ≥ 5 ошибок валидации | см. README (15+), `js/validation.js` |
| 14 | Поиск и фильтрация | Меню: поиск, категории, цена |
| 15 | Адаптивность: ПК, планшет, телефон | `css/pages.css` (900 / 600 / 480 px) |
| 16 | Единый дизайн | один набор стилей, общие меню и футер |
| 17 | Футер: О нас, Контакты, Конфиденциальность, Условия, соцсети, © | `js/layout.js`, `pages/privacy`, `pages/terms` |
| 18 | Структура проекта | см. README |
| 19 | HTML / CSS / JS | семантика, формы, Flexbox, Grid, media queries, hover, transition; события, DOM, валидация, динамика |
